How does the interaction work? +

This is a two-dimensional differential-growth study. Seven seeded contours spread across the surface and continue beyond its edges. Each step balances local repulsion with neighbour cohesion, then adds points where a line stretches. Nearby lines also make room for one another.

Each contour has its own line thickness, curl, drift, directional pressure, pulse, and outward growth. Its line width changes along the contour as it develops. Variation changes how strongly those rules respond. Move the pointer to draw the nearest section toward it; drag on touch screens. The contours keep evolving after the canvas fills, so you can continue reshaping them. Spacing changes the repulsion distance, while Speed changes playback. Reset replays the current seed with your settings; New seed starts a different field.
